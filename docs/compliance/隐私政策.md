# 仓管家（手机版）隐私政策

版本号：1.2
更新日期：2026年11月28日
生效日期：2026年11月2日

**【重要提示】**
感谢您使用仓管家手机版（以下简称"本应用"）。本应用是一款运行在您手机上的本地库存管理工具，不设账号体系，不设云端服务器，我们不会通过网络接收到您的任何业务数据。

《中华人民共和国个人信息保护法》第十七条要求我们在处理个人信息前向您告知相关事项。请您在使用前仔细阅读本政策。您勾选"我已阅读并同意"并点击"同意并继续"，即表示您已充分理解并同意本政策；如您不同意，本应用将无法为您提供服务，您可点击"不同意，退出"结束使用。

## 二、我们处理的个人信息、处理目的与方式
本应用的全部业务数据默认保存在您手机的应用私有目录中，其他应用无法读取。
1. 库存与出售记录：商品编号、品牌、类别、型号、成色、进价、售价、数量、货位、备注、买家称呼、出售日期、交易金额。
  目的：实现库存登记、出入库管理、销售记录与统计报表。
  方式：您手动录入或从表格文件导入，仅存储在本机。
2. 商品照片：您主动拍摄或从相册选择的图片，以及您填写的照片备注。
  目的：为商品留档、便于核对实物。
  方式：压缩后存储在本机；仅在您开启"数据共享到电脑端"时同步到您自己的电脑。
3. 拍照识别时的图像内容：仅在您使用"拍照识别型号"或"扫二维码"功能时，于手机内存中做离线文字识别。
  目的：免去手动输入型号。
  方式：识别在本地完成，原始图像不留存、不上传，识别结束即从内存释放。
4. 应用配置：主题、显示列、编号前缀、电脑地址、连接会话令牌。
  目的：记住您的使用偏好与连接状态。
  方式：存储在本机。
5. 崩溃日志：仅当应用异常退出时记录发生时间、应用版本号与错误堆栈。
  目的：定位并修复故障。
  方式：保存在应用私有目录，下次启动向您展示后立即删除。
6. 局域网连接记录：当您连接电脑时，电脑端会记录来源 IP 地址、访问时间、访问的接口与处理结果。
  目的：安全审计与故障排查，并满足《中华人民共和国网络安全法》第二十三条关于网络日志留存不少于六个月的要求。
  方式：保存在您自己的电脑本地，自生成之日起保留 180 天。

我们不会收集您的通讯录、短信、通话记录、位置信息、设备标识符（IMEI、IMSI、MAC 地址、OAID、Android ID）、应用列表、剪贴板内容、生物识别信息，也不会读取与您所选照片无关的相册内容。

## 三、系统权限清单与调用时机
本应用仅申请以下两项系统权限，均在使用对应功能时向您申请，您可以拒绝，且拒绝不影响其他功能的正常使用：
1. 相机（CAMERA）
  用途：① 拍摄商品照片；② 拍照识别商品型号；③ 扫描电脑端二维码建立连接。
  调用时机：仅在您点击上述按钮时申请。
  拒绝的后果：无法使用拍照相关功能，但您仍可手动输入型号、从相册选择照片、手动填写电脑地址。
2. 网络访问（INTERNET）
  用途：在您开启"数据共享到电脑端"后，与同一局域网内您自己的电脑通信。
  说明：该权限在安装时授予，除下述"版本更新检查"外，不会被用于访问互联网上的任何服务器。
3. 版本更新检查（2026年11月28日新增）
  用途：仅当您在"设置 → 版本更新"中点击"检查更新"时，应用会向 GitHub 的两个只读域名（raw.githubusercontent.com、api.github.com）请求版本号信息文件，用于比对当前版本；应用不发送您的任何业务数据。
  说明：下载新版本安装包通过系统浏览器完成，应用内不做下载、不申请安装相关权限；除此之外应用不会连接任何互联网服务器。
本应用不申请存储权限、位置权限、通讯录权限、电话权限、短信权限、日历权限。从相册选择照片使用系统提供的照片选择器，仅向本应用开放您主动选中的图片。

## 四、委托处理、共享、转让与公开披露
1. 本应用未集成任何第三方 SDK（广告、统计、推送、地图、支付、社交登录等均无），不存在向第三方 SDK 提供个人信息的情形。
2. 文字识别（OCR）在您的手机本地完成，识别模型随安装包内置，图像数据不出您的设备。
3. 我们不会向任何第三方出售、共享、转让您的个人信息，也不会公开披露。
4. 仅在下列法定情形下我们可能对外提供信息：依据法律法规规定，或应诉讼、政府主管部门强制性要求。

## 五、存储地点与存储期限
1. 存储地点：全部数据存储在您手机本地，不涉及个人信息出境。
2. 存储期限：
  - 库存、出售记录与商品照片：由您自行保管，直至您在应用内删除、清空数据或卸载本应用；
  - 崩溃日志：保留至下次启动展示后即删除；
  - 电脑地址与会话令牌：保留至您点击"断开"或卸载应用；会话令牌在电脑端 12 小时后自动失效；
  - 连接码：不保存在手机中，仅本次连接过程使用；
  - 电脑端访问日志：自生成之日起保留 180 天，到期自动清除。
3. 您卸载本应用后，应用私有目录内的全部数据随之删除。

## 六、您的权利
依据《中华人民共和国个人信息保护法》第四十四条至第四十七条，您对自己的个人信息享有以下权利：
1. 查阅、复制：进入"设置 → 数据管理 → 导出全部数据"，可将全部库存、出售记录与照片导出为 JSON 备份文件，由您自行保存或转发。
2. 更正、补充：在库存列表点击任一记录即可修改。
3. 删除：可逐条删除；也可在"设置 → 数据管理 → 清空手机数据"一次性删除本机全部数据。
4. 撤回同意：进入"设置 → 隐私与数据 → 撤回同意并清除数据"，撤回后本机数据将被清除且应用退出。撤回同意不影响撤回前基于您的同意已进行的处理。
5. 注销：本应用无账号体系，无需注销；卸载应用即终止全部处理活动。
6. 投诉举报：如您认为我们的处理行为损害了您的合法权益，可向网信、电信、公安、市场监管等主管部门投诉举报，也可发送邮件至上述邮箱，我们将在 15 个工作日内答复。

## 七、我们采取的安全措施
1. 数据隔离：全部数据存放于应用私有目录，其他应用无法读取；已关闭系统备份与云备份，数据不会被同步到云端。
2. 访问控制：您可在"设置 → 隐私与数据 → 启动验证"开启启动验证，开启后每次打开应用需先通过手机锁屏密码或指纹验证，防止他人拿到手机后查看您的库存数据。
3. 传输安全：仅在您主动开启共享时，与局域网内您自己的电脑通信；会话令牌与来源 IP 绑定、12 小时过期、同一 IP 连接失败 5 次锁定 10 分钟；应用拒绝连接公网地址，避免数据被发往互联网。
4. 最小必要：仅申请相机权限；照片选择使用系统选择器，不申请存储权限。
5. 应急处置：一旦发生或可能发生个人信息泄露、篡改、丢失，我们将按《中华人民共和国个人信息保护法》第五十七条的要求立即采取补救措施，并通知您和相关主管部门。

## 八、未成年人保护
本应用面向经营者提供库存管理功能，不面向不满十四周岁的未成年人。若您是未满十四周岁的儿童，请在监护人陪同下阅读本政策，并在取得监护人同意后使用。

## 九、本政策的更新
1. 本政策版本号变更时，我们会在您下次启动应用时重新展示并征得您的同意。
2. 对于重大变更（如处理目的、信息种类、共享对象发生变化），我们会以显著方式提示。
3. 当前版本号可在"设置 → 隐私与数据"中查看。

## 十、其他
1. 本应用不进行自动化决策、用户画像与定向推送，不向您发送商业广告。
2. 本政策适用中华人民共和国大陆地区法律。
3. 本政策自 2026 年 11 月 2 日起生效。
