# 个人信息收集使用清单

产品：仓管家手机版 v1.32.0（`com.cangguanjia.app`）  
对应版本：隐私政策 v1.1  
更新日期：2026-11-02

> 本清单是"告知"的落地形式，也是应用商店隐私标签（数据安全表单）的填写依据。
> 任何字段增删都必须同步更新本清单与隐私政策，并递增 `Legal.VERSION`。

---

## 一、处理活动总览

| 编号 | 信息类别 | 是否个人信息 | 敏感程度 | 处理目的 | 法律依据 | 存储位置 | 保存期限 | 对外提供 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| P1 | 库存记录（编号/品牌/类别/型号/成色/进价/售价/数量/货位/备注） | 部分（可关联经营者） | 一般 | 库存登记、出入库、统计 | PIPL 13(1) 同意 | 手机应用私有目录 | 用户删除或卸载前 | 仅在用户开启共享时传给自己的电脑 |
| P2 | 出售记录（含**买家称呼**、出售日期、金额、收货地址） | 是（买家称呼可识别到人） | 一般 | 销售记录、对账、买家统计 | PIPL 13(1) 同意 | 同上 | 同上 | 同上 |
| P3 | 商品照片、照片备注 | 可能是（若照片含人脸/单据） | 一般 | 商品留档、核对实物 | PIPL 13(1) 同意 | 同上 | 同上 | 同上 |
| P4 | 拍照识别时的图像帧 | 可能是（若画面含人脸） | 一般 | 离线文字识别 | PIPL 13(1) 同意 | **不存储**（仅内存） | 识别完成即释放 | 无 |
| P5 | 应用配置（主题/显示列/编号前缀/电脑地址/会话令牌） | 部分（电脑地址可定位设备） | 一般 | 记住偏好与连接状态 | PIPL 13(1) 同意 | 手机应用私有目录 | 断开连接或卸载前；令牌 12h 失效 | 无 |
| P6 | 崩溃日志（时间/版本号/堆栈） | 否（不含业务数据） | — | 定位故障 | PIPL 13(1) 同意 | 应用私有目录 | 下次启动展示后删除 | 无（用户主动截图反馈除外） |
| P7 | 局域网访问日志（时间/来源 IP/方法/接口/状态码） | 是（IP 属个人信息） | 一般 | 安全审计、故障排查 | 《网络安全法》23 条法定义务 + PIPL 13(3) | 用户自己的电脑 `data/logs/` | **180 天** | 无 |

**明确不收集**：通讯录、短信、通话记录、精确/粗略位置、IMEI/IMSI/MAC/OAID/Android ID 等设备标识符、
应用列表、剪贴板、相册全量遍历、生物识别信息、身份证件信息、银行卡与支付信息。

## 三、第三方 SDK 清单

**本应用未集成任何第三方 SDK。** 无广告、无统计、无推送、无地图、无支付、无社交登录、无崩溃上报平台。

| 组件 | 性质 | 是否联网 | 是否收集个人信息 |
| --- | --- | --- | --- |
| ONNX Runtime Android 1.18.0 | 本地推理运行时（随包） | 否 | 否 |
| PP-OCR det/rec/cls 模型 | 本地模型文件（随包） | 否 | 否 |
| AndroidX Core | 系统兼容库 | 否 | 否 |
| 系统 WebView | 系统组件 | 仅加载本地页面 | 否（页面代码自有） |

新增任何 SDK 前必须：① 在本表登记名称、版本、收集字段、用途、隐私政策链接；② 在首启同意页披露；
③ 通过回归断言（清单中列出即视为已披露）。未登记不得合入。

## 四、数据流

```
┌────────────────────────── 手机（应用私有目录） ──────────────────────────┐
│                                                                          │
│  用户录入 ──► 库存/出售记录 ──┐                                          │
│  拍照/选图 ─► 商品照片 ───────┼──► localStorage（明文，沙箱隔离）        │
│  拍照识别 ──► 图像帧 ─────────┘         │                                │
│      （仅内存，识别后释放）              │                                │
│                                          ▼                                │
│                              导出：JSON ──► 系统分享面板 ──► 用户自选去向 │
│                                          │                                │
│                              开启共享 ──► HTTP（仅私有网段）              │
└──────────────────────────────────────────┼───────────────────────────────┘
                                           ▼
                        电脑（用户自己的设备，同一局域网）
                        SQLite 明文 + data/logs/access-YYYYMMDD.log（180 天）
```

**不存在**到开发者服务器、云平台或任何第三方的数据流。

## 六、与最小必要原则的对照

| 功能 | 是否必需该类信息 | 判断 |
| --- | --- | --- |
| 库存管理 | 型号、数量、价格等为功能本体 | 必需 |
| 买家称呼 | 对账与买家统计需要；可留空 | 必需但**非强制填写**（空白可保存） |
| 商品照片 | 可选功能 | 用户不拍照不影响任何其他功能 |
| 拍照识别 | 可选效率功能 | 可完全手动输入替代 |
| 局域网共享 | 可选功能 | 默认关闭，需用户主动开启 |
| 崩溃日志 | 故障定位必需，且不外传 | 属"实现目的所必要" |
| 访问日志 | 法定义务，非产品需要 | 依法留存，且**不记录业务内容** |

结论：不存在"与提供服务无关"的收集项；不存在"不授权就不给用"的非必要信息。
