# 仓管家 · 仓库管理系统

纯本地运行的仓库管理桌面工具（Windows 单文件 exe），数据存放在本机 SQLite 数据库，不联网、不上传。

## 功能

| 模块 | 说明 |
| --- | --- |
| 多仓库 | 顶部工具栏「仓库」下拉随时切换；每个仓库一套独立数据库、独立编号（各自从 WL-00001 起）、独立统计。「仓库管理」支持新建（空白 / 复制当前仓数据）、重命名、移除（文件保留在数据目录） |
| XLSX 导入 | 智能识别表头（支持 商品编码/牌子/规格型号/新旧程度/售价(元)/「单格」/库位/「G (货架)」等带括号列名… 等常见叫法），字段映射可在导入向导中**手动下拉调整**，实时预览 |
| 按型号合并（主推） | **以「型号」判断是否重复**：型号相同 → 更新原记录（不新增）；型号不存在 → 新增。自动忽略大小写与多余空格（`ABB PFEA111` = `abb  pfea111`）；型号为空/`-`/`无型号` 不参与判定，一律新增 |
| 重复预判 | 导入向导预览区带「重复判断」列，逐行标注 **更新（已存在）/ 新增 / 文件内重复 / 新增（无型号）**，并统计「本次将更新 N 条 · 新增 M 条」 |
| 三种导入方式 | 按「型号」合并（默认，重复则更新）/ 追加导入 / 覆盖全部（先清空，编号仍接着原有编号排） |
| 合并策略 | 「空值不覆盖原数据」（导入行为空则保留原值）、「清理库中同型号重复行」（库中同型号多条时只留一条） |
| 重复检查 | 「数据 → 按型号检查重复」列出库中重复录入的型号、重复条数、编号，可一键复制 |
| 编号自动生成 | 导入或新增时编号留空将自动生成（`WL-00001` 顺序递增，**承接库中已有最大编号**，覆盖导入也不会从 1 重来） |
| 全字段管理 | 编号、品牌、品类、型号、成色、价格、数量、货架、上架状态（可选项下拉）、备注 |
| 上架状态 | 编辑弹窗中为下拉选项；表格中双击该列可直接选择「已上架 / 未上架」；支持批量上架 / 下架 |
| 筛选与搜索 | 品牌、品类、成色、货架、上架状态、价格区间、全局关键词（含模糊搜索） |
| 排序 | 点击任意表头升序 / 降序切换 |
| 分页 | 每页 100 / 200 / 500 / 1000 / 全部，十万级数据流畅 |
| 复制 | 右键即可：复制单元格 / 复制整行 / 复制选中行（TSV，可直接粘贴进 Excel）/ 复制整列 / 复制全部筛选结果 / 复制为 JSON |
| 编辑 | 双击单元格打开编辑弹窗，支持批量新增列显示设置 |
| 数据分析 | 记录数、库存总量、库存总价值、上架率、平均价格 5 张指标卡 + 品牌TOP10、品类占比、成色分布、价格区间、货架占用、上/下架 6 张图表 |
| 统计报表 | 一键导出「明细 + 统计概览 + 品牌/品类/成色/货架统计 + 价格区间」多工作表 XLSX |
| 导出 | 当前筛选结果或全部数据，导出文件带表头样式、冻结首行、自动筛选 |
| 文件共享 | 再同一个网段上，主机可以共享到客户端，但客户端仅支持查阅，需要主机的授权才可以修改数据。 |


## 快捷键

`Ctrl+I` 导入 · `Ctrl+S` 导出 · `Ctrl+N` 新增 · `Ctrl+E` 编辑 · `Ctrl+C` 复制选中 · `Ctrl+A` 全选本页 · `Ctrl+F` 搜索 · `F5` 刷新 · `Delete` 删除选中

## 数据存放

- 数据库：`data/warehouse.db`（与 exe 同目录；若目录无写权限则自动写到 `%APPDATA%\WarehouseManager`）
- 窗口大小、每页条数、列显示设置保存在 `data/settings.json`

## 从源码运行

```bash
py -3.10 -m venv .venv310
.venv310/Scripts/python -m pip install openpyxl pyinstaller
.venv310/Scripts/python main.py
```

## 打包 exe

```bash
.venv310/Scripts/python build.py     # 产物: dist/仓管家-仓库管理系统.exe
```

## 测试

```bash
.venv310/Scripts/python tests/test_logic.py
```
